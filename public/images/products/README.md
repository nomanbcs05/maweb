# Product Images Directory Structure

This folder contains product images organized by category:

- `/cakes/` - Cake products
- `/breads/` - Bread products
- `/pastries/` - Pastry products
- `/ice-cream/` - Ice cream and frozen desserts
- `/cookies/` - Cookies and biscuits
- `/snacks/` - Savory snacks
- `/sweets/` - Sweets and confections

## Image Guidelines

- Use high-quality images with transparent or clean backgrounds
- Recommended dimensions: 800x800px (square) for product cards
- Supported formats: JPG, PNG, WebP
- Name files using kebab-case: `product-name.jpg` (e.g., `chocolate-cake.jpg`)
